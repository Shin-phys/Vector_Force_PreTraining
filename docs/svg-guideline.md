# 図（SVG）の作成規約

`assets/figures/<単元>/<問題ID>.svg` に1問1ファイルで置きます。

## 1. 基本

- `viewBox="0 0 600 400"` 固定。`width` / `height` 属性は付けない
- **力の矢印は描かない**（矢印はアプリが描く）
- 文字は最小限。物体名（A・B）、角度（θ=30°）、面の性質（あらい床／なめらかな床）程度
- 色は直値ではなく `src/css/tokens.css` のCSS変数を使う。ダークモードとハイコントラストに追随する
- ハッチ（`url(#hatch)`）は `assets/parts/defs.svg` で定義され、アプリ起動時に1回だけ読み込まれる

## 2. 使うクラス

| クラス | 用途 |
|---|---|
| `fig-body-a` / `fig-body-b` | 物体の塗り（薄い青／薄い橙）。輪郭は `data-role="outline"` で3px |
| `fig-scenery` | 床・壁・斜面・滑車などの線（3px） |
| `fig-string` | 糸（1.5px） |
| `fig-spring` | ばね（ジグザグ・山6個が標準） |
| `fig-hatch` | ハッチ塗り |
| `fig-guide` / `fig-guide-solid` | 速度など補助表示（破線・グレー） |
| `fig-label` | 物体名などの大きめの文字 |
| `fig-note` | 注記の小さい文字 |

## 3. 必須の id・data属性

| 要素 | 属性 | 用途 |
|---|---|---|
| 注目物体 | `id="body-a"` / `id="body-b"`、`data-role="body"` | 判定対象の物体。`<g>` で包む |
| 輪郭 | `data-role="outline"` | 物体の輪郭線 |
| 作用点候補 | `data-snap="<id>"` | 不可視の `<circle r="1" opacity="0">` で位置だけ示す |
| 作用点の種類 | `data-snap-type="CENTER｜CONTACT｜ATTACH"` | 重心／接触点／糸・ばねの取付点 |
| 内向き法線 | `data-inward="<角度>"` | その作用点で物体の内側を向く向き（数学座標の度）。CENTER 以外は必須 |
| 所属物体 | `data-body="a"` / `"b"` | 省略時は id の先頭（`a-bottom` → `a`）から決まる |
| 角度アンカー | `data-anchors="60,150"` | その作用点でだけ優先したい角度があるとき（任意） |
| 背景物 | `data-role="scenery"` | 床・壁・斜面・糸・ばね・滑車など |

**作用点候補は「正解の点」だけでなく、誤って選ばれうる点もすべて置きます。**
重心・各接触点・取付点を網羅してください。これが無いと誤概念を検出できません
（例：垂直抗力を重心から描く＝`a-center` が候補に無いと入力すらできない）。

## 4. 作用点の丸と輪郭の関係

矢印の始点には半径7pxの丸を描きます。この丸は**輪郭線の内側に接する**よう配置されます。

- 論理座標（判定に使う作用点）は輪郭線上のまま
- 描画時のみ `data-inward` の向きへ半径分だけ中心をずらす（`renderer.dotCenter()`）

接触した2物体で作用・反作用を描くと、2つの丸が輪郭線を挟んで反対側に並び、
「別の物体にはたらく力」であることが図から読み取れます。

## 5. 重なるベクトル

作用点が違っても**同じ直線上**にある力（水平面上の重力と垂直抗力など）は、
描画時のみ直交方向へ6pxずつずらします（`renderer._offsets()`）。論理データは変更しません。

## 6. 図の作り方

A編の図は `tools/` の外で Python スクリプトから生成しました（座標計算を手で書かないため）。
新しい図は手書きでも構いませんが、斜面など角度が絡む図は計算して座標を出すことを勧めます。
作ったら `node tools/validate.mjs` で、JSONの `snap` と図の `data-snap` が一致しているか確認してください。
