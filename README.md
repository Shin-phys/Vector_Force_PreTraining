# 力の作図トレーナー

高校物理の「力の作図」を、作用点・向き・大きさ・力の名称・**力を及ぼす相手**まで含めて
生徒自身に描かせ、典型的な誤概念を検出して解説を返すWebアプリです。
サーバー側の処理は無く、ファイルを置くだけで公開できます。

## 生徒に使ってもらう（GitHub Pages）

リポジトリ：<https://github.com/Shin-phys/Vector_Force_PreTraining>

GitHub の **Settings → Pages → Build and deployment → Deploy from a branch** で
`main` / `/ (root)` を選ぶと、そのまま公開されます（ビルド不要の静的サイトです）。

公開URL：`https://shin-phys.github.io/Vector_Force_PreTraining/`
解答例一覧：`https://shin-phys.github.io/Vector_Force_PreTraining/answers.html`

生徒はこのURLを開くだけです。進捗は各自の端末のブラウザに保存されます。

## 手元で動かす

問題データ（JSON）と図（SVG）を読み込むため、`index.html` をダブルクリックしても動きません。
ローカルサーバー経由で開いてください。

**Mac：** `tools/serve.command` をダブルクリック（ブラウザが自動で開きます）

**ターミナル：**

```bash
cd "力の矢印アプリ"
python3 -m http.server 8000
# → http://localhost:8000/
```

**公開する：** 上記のGitHub Pages、または任意のWebサーバーにフォルダの中身を置くだけです。

## 画面

| 画面 | 内容 |
|---|---|
| TOP | クリア状況、これまでに多かったつまずき、最近のテスト結果、設定（記号表記・ダークモード・ハイコントラスト） |
| 出題範囲 | 単元・タグで絞り込み、「この範囲を順に解く」「ランダム5題」、問題を直接選ぶ |
| 作図 | ①力の名称を選ぶ → ②何から受ける力かを選ぶ → ③作用点をタップして矢先までドラッグ。描いた力は一覧パネルから個別に削除できる |
| 結果 | 自分の図と正解の重ね合わせ、力1本ごとの判定、誤概念ごとの解説（大きさを判定する設定のときは大きさの関係も） |

- **練習（一問一答）**：1回目の誤りでは誤り箇所を示さず段階ヒント（①重力はあるか ②触れているものは何か ③接触箇所を強調）。2回目で正解と解説を出します
- **テスト**：まとめて解答し、最後に採点。**誤概念別の集計**が出ます。前パートの矢印は提出まで表示しません
- 進捗はこの端末のブラウザ（localStorage）に保存されます。ログイン不要

### 大きさの判定は切り替え式（既定OFF）

まずは「力を過不足なく挙げられるようにする」段階に集中できるよう、**大きさの判定は既定でOFF**です。
TOPの設定、または出題範囲画面の「大きさも判定する」で切り替えます（設定は保存されます）。

- **OFF**：力の名称・相手・作用点・向きだけを判定します。矢印の長さは自由（見た目は5段階に丸められます）
- **ON**：矢印の長さを**5段階**に丸め、問題に定義された関係（N＜mg、T＞mg、作用・反作用の等大、1本の糸の張力など）を段階の大小で判定します
  - ドラッグ中は長さの目盛りが出ます。**ドラッグに精度は要りません**。確定後に一覧パネルの **−／＋** で段階を調整できます
  - 力の名称・作用点・向きが全部正しく、大きさだけ誤っている場合は「力は正しく描けています。大きさだけ見直しましょう」と返します
  - テストモードでは「力1本単位の部分点」と「大きさの関係」を別々に集計します
  - 関係が定義されていない力の長さは判定しません（質量や摩擦係数が無いと決まらない大小は問題側で定義していません）

**`answers.html`** を開くと、全問題の正解を重ねた一覧が出ます（授業準備・答え合わせ用）。

## 収録状況

A編（力学基礎編）20題を実装済みです。B〜H編は別紙カリキュラム（`docs/curriculum.md`）のとおり未着手で、
フォルダだけ用意してあります。エンジンは単元を問わず動きます。

| 問題 | 場面 | ねらい |
|---|---|---|
| A01〜A03 | 机の上／糸でつるす／ばねでつるす | 作用点（接触面・取付点）と力の相手 |
| A04〜A07 | 投げ上げの最高点／斜方投射の上り・最高点・下り | 「運動の向きの力」を描かない。A05〜A07はセット問題 |
| A08〜A10 | あらい床をすべる／押しても動かない／ばねに押される | 摩擦力の向き、つりあい、弾性力の向き |
| A11〜A13 | 斜め上に引かれ等速／壁に押し付ける／2本の糸 | N＝mg とは限らない、3力のつりあい |
| A14〜A16 | なめらかな斜面／あらい斜面で静止／すべり上がる | 分力を力として描かない、摩擦の向き |
| A17〜A20 | 接触2物体／重ねた2物体／滑車／加速するエレベーター | 作用・反作用、重力は伝わらない、1本の糸の張力、慣性力を描かない |

## フォルダ

```
index.html            … アプリ本体（画面はJSで切り替え）
answers.html          … 解答例一覧（先生用）
docs/                 … 仕様・規約
  spec.md             … 実装仕様書 v2.0 ＋ 実装メモ
  curriculum.md       … 収録問題一覧（全95題）と実装状況
  svg-guideline.md    … 図の描画規約
  data-schema.md      … 問題JSONのスキーマ
src/css/tokens.css    … 色・線幅の変数（SVGと共有）
src/js/canvas/        … 角度変換・スナップ・描画・入力
src/js/logic/         … 判定・大きさの関係・誤概念・採点
src/js/data/          … 読み込み・localStorage
src/js/ui/            … 各画面
assets/figures/<単元>/ … 問題の図（1問1ファイル）
assets/parts/defs.svg … ハッチなどの共通パーツ
data/index.json       … 全問題の一覧（出題の起点）
data/forces.json      … 力の種類・相手・ダミーの定義
data/feedback.json    … 誤概念コードと解説文
data/problems/<単元>/  … 問題データ
tools/validate.mjs    … JSONと図の整合性チェック
tools/make-index.mjs  … index.json の作り直し
tools/serve.command   … ローカルサーバー起動（Mac）
```

## 問題を追加する

1. `assets/figures/<単元>/<ID>.svg` に図を作る（規約は `docs/svg-guideline.md`）
   - 力の矢印は描かない
   - **作用点候補は、正解の点だけでなく誤って選ばれうる点もすべて置く**（重心・各接触点・取付点）
2. `data/problems/<単元>/<ID>.json` に問題データを書く（スキーマは `docs/data-schema.md`）
   - `availableForces` に、その問題で検出したい誤概念のダミー（`DUMMY_*`）を混ぜる
   - 新しい解説文が要るときは `data/feedback.json` にコードを足す
3. 一覧を作り直す

```bash
node tools/make-index.mjs
node tools/validate.mjs
```

4. コミットして push すれば、GitHub Pages の公開内容も更新されます

```bash
git add -A
git commit -m "A編に◯◯を追加"
git push
```

push すると GitHub Actions（`.github/workflows/validate.yml`）が `validate.mjs` を実行し、
図とJSONの食い違いがあれば赤くなって知らせます。

`validate.mjs` は、図の `data-snap` と JSON の `snap` の対応、未定義の力や相手、
15°刻みでない角度、`feedback.json` に無い誤概念コード、作用点候補の不足などを検査します。
「ダミーの力が1つも入っていません」の警告は、静止したつりあいの問題（A01〜A03、A18a）では意図的です。
